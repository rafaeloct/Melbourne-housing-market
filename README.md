# Melbourne Housing Market - Analisis Data Eksploratif (EDA)

Repositori ini berisi proyek Analisis Data Eksploratif (EDA) untuk mengeksplorasi tren, lokasi, dan faktor-faktor yang memengaruhi harga pasar properti di Melbourne, Australia[cite: 3].

## 📋 Tentang Proyek
Proyek ini dibuat untuk menganalisis karakteristik harga rumah di Melbourne menggunakan Python dan Jupyter Notebook. Tujuannya adalah untuk menemukan pola korelasi antara variabel seperti lokasi, jumlah kamar, tipe bangunan, dan faktor lainnya terhadap harga jual properti.

## 🛠️ Teknologi & Library yang Digunakan
- **Python**
- **Jupyter Notebook** (`.ipynb`)
- **Pandas & NumPy** (Manipulasi dan pembersihan data)
- **Matplotlib & Seaborn** (Visualisasi data)

## 📂 Struktur File di Repositori
- `Melbourne housing market.ipynb`: File utama Jupyter Notebook yang berisi seluruh tahapan kode, mulai dari *data preprocessing*, EDA, hingga visualisasi.
- `.gitignore`: Pengaturan file yang diabaikan oleh Git (termasuk file *checkpoint* dan *cache* Python).
- `README.md`: Dokumentasi dan penjelasan proyek.
